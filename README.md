# AuctionHub - Sorting Practice Lab

Assignment implementation for Data Structures and Algorithms.

## Repository Structure
- `auctionhub.cpp`: C++ implementation of the 5 required sorting algorithms (Insertion Sort, Selection Sort, Interchange Sort, Bubble Sort with Early Stop, Quick Sort with Median-of-Three).
- `REFLECTION.md`: Comprehensive reflection answering technical justifications, measured runtimes, bug analysis, prompt discipline, and worst-case analysis.
- `test_data/`:
  - `small.txt`: 4 sample bids for basic correctness testing.
  - `large.txt`: 100,000 synthetic bids for performance benchmarking.
- `screenshot_runtime.png`: Terminal execution screenshot.

## Build and Run
```bash
g++ -O2 -std=c++17 auctionhub.cpp -o auctionhub.exe
./auctionhub.exe
```
